# ltree

Linux/POSIX環境向けの軽量な `ltree` コマンドです。ディレクトリを再帰的に読み込み、名前順の木構造とファイル数・ディレクトリ数を表示します。

## Build

```sh
make
```

システムコマンドとしてインストールする場合:

```sh
sudo make install
ltree .
```

## Usage

```sh
./ltree [options] [directory ...]
```

引数を省略するとカレントディレクトリを表示します。

`ls` と同じ感覚で短いオプションを組み合わせられます。

```sh
ltree -la
ltree -lh
ltree -ltr
ltree -lS
ltree -R
```

| Option | Meaning |
| --- | --- |
| `-a`, `--all` | `.` で始まるエントリも表示 |
| `-d`, `--directory` | ディレクトリの中へ入らず、指定したディレクトリ自身を表示 |
| `-f` | 隠しファイルを含め、ソートしない |
| `-l` | permission・link数・uーザー・グループ・サイズ・更新日時を表示 |
| `-h`, `--human-readable` | `-l` のサイズを読みやすい単位で表示 |
| `-n`, `--numeric-uid-gid` | `-l` 形式でユーザーとグループを数値表示 |
| `-F`, `--classify` | 種類を表す記号を末尾に付加 |
| `-p` | ディレクトリの末尾に `/` を付加 |
| `-t` | 更新日時順（新しい順） |
| `-S` | サイズ順（大きい順） |
| `-r`, `--reverse` | 並び順を反転 |
| `-R`, `--recursive` | 深さ制限なしで再帰表示 |
| `-L N`, `--depth N` | 表示する深さを `N` 段に制限 |
| `--dirs-only` | ディレクトリだけを表示 |
| `--dirs-first` | ディレクトリを先に並べる |
| `--full-path` | 各エントリのフルパスを表示 |
| `--one-file-system` | 他のファイルシステムに移動しない |
| `--du` | 各ディレクトリに配下全体の合計サイズを表示（`-l` を含む） |
| `--color=WHEN` | `always`, `auto`, `never` から色の付け方を選択 |
| `--ascii` | ASCIIの枝記号を使う |
| `--unicode` | Unicodeの罫線文字で枝を表示（デフォルト） |
| `--no-summary` | 末尾の集計を表示しない |

`ltree` はデフォルトで指定ディレクトリの直下1階層だけを表示します。全階層は `-R`、指定した深さまでは `-L N` を使います。

`ltree` はシンボリックリンクを追跡しません。端末への出力時はファイル種別に応じて自動的に色を付け、パイプやファイルへの出力時は色を無効にします。Unicode枝のインデントは標準の `tree` と同じく、縦線の後ろにUTF-8のNBSPを使って描画します。

`--du` はディレクトリエントリ自体のサイズではなく、配下のファイル、ディレクトリ、シンボリックリンクの論理サイズを合計します。シンボリックリンク先は追跡しません。
